# Heritability in Plant Breeding
This GitHub respository contains `R` and `SAS` codes for a number of methods for heritability estimation in plant breeding and thus mostly *heritability on an entry-mean basis*. Its aim is to provide helpful examples for researchers and practicioners in the field of plant breeding or general cultivar evaluation trials.

> ### 📦 There is now an R package: `heritable`
> Most of the heritability measures demonstrated in this repository are now available in the **[`heritable`](https://github.com/anu-aagi/heritable)** R package, which computes various heritability estimates directly from a fitted mixed model.
> If you just want the numbers, the package is usually the easier route; the example scripts here remain useful for understanding *how* each estimator is computed.
> * Package: <https://github.com/anu-aagi/heritable>
> * Documentation: <https://anu-aagi.github.io/heritable/>
