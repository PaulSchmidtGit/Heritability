## Alternative Estimation Methods for H² on Entry-Mean Basis in ASReml-R
For information on how to use these codes, plase go to the [main page](https://github.com/PaulSchmidtGit/Heritability/tree/master/Alternative%20Heritability%20Measures)

> 📦 Most of these measures are also available in the **[`heritable`](https://github.com/anu-aagi/heritable)** R package (docs: <https://anu-aagi.github.io/heritable/>).

### Two ASReml-R versions
* The `.R` scripts in **this** folder were written for **ASReml-R 3.0** (the original examples).
* The subfolder **[`ASReml 4.2 (community-contributed)`](ASReml%204.2%20(community-contributed))** contains the same examples adapted to **ASReml-R 4.2.x** syntax. ⚠️ Those updated scripts were kindly contributed by [@mpeddu](https://github.com/mpeddu) via [pull request #5](https://github.com/PaulSchmidtGit/Heritability/pull/5) and were **not authored or tested by us** — please review and test them yourself.
